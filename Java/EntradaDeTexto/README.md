# 💬 Saudação Personalizada (Java Swing)

Uma aplicação desktop simples desenvolvida em **Java** utilizando a biblioteca gráfica **Swing**. O programa exibe uma interface interativa onde o usuário digita seu nome e recebe uma mensagem de boas-vindas personalizada em uma caixa de diálogo.

---

## 🚀 Funcionalidades

- **Interface Gráfica (GUI):** Janela interativa centralizada na tela com campo de entrada (`JTextField`), texto descritivo (`JLabel`) e botão de ação (`JButton`).
- **Validação de Entrada:** Impede o envio com o campo em branco ou preenchido apenas com espaços, exibindo um alerta de aviso (`JOptionPane`).
- **Boas-Vindas Personalizadas:** Exibe uma mensagem contendo o nome digitado em uma caixa de diálogo informativa.
- **Experiência do Usuário (UX):** Limpa o campo de texto automaticamente após a confirmação e foca o cursor de volta para facilitar digitações subsequentes.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java (JDK 8 ou superior)
- **Biblioteca GUI:** Java Swing / AWT (`FlowLayout`)

---
