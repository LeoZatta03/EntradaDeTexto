# 🔐 Cofre Secreto - Login (Java Swing)

Uma aplicação desktop de autenticação desenvolvida em **Java** com **Swing**, demonstrando conceitos fundamentais de interfaces gráficas (GUI), gerenciamento de layouts, validação de formulários e manipulação de eventos.

---

## 🚀 Funcionalidades

- **Autenticação Simples:** Validação de credenciais de usuário e senha com exibição de mensagens de sucesso ou erro.
- **Exibir/Ocultar Senha:** Opção via `JCheckBox` para alternar a visibilidade da senha (`JPasswordField`).
- **Barra de Menus (`JMenuBar`):**
    - **Sobre:** Diálogo com informações sobre o projeto.
    - **Sair:** Caixa de confirmação antes de encerrar a aplicação.
- **Limpeza de Campos:** Botão para resetar as entradas e redefinir o foco para o campo de usuário.
- **Feedback Visual:** Atualização de status em tempo real na interface através de rótulo informativo.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java (JDK 8 ou superior)
- **Biblioteca GUI:** Java Swing / AWT (`BorderLayout`, `GridLayout`, `FlowLayout`)
